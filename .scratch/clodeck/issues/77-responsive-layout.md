# 77: The layout works on a phone

> *This was generated by AI during triage.*

**What to build:** Layout-e clodeck — rail (icon ha) ▸ project sidebar ▸ chat stage ▸ bottom drawer — faghat
baraye desktop tarahi shode. Hich breakpoint-i nadarad: rail `w-[52px]`, sidebar `w-72` hamishe baz, drawer
`h-[42vh]`. Ru-ye phone (az 360px) safhe horizontal overflow mikhonad va sidebar-ra nemishe bast. In ticket
layout ra baraye mobile reflow mikone — **faqat layout**, bedoone gesture ya touch-specific behaviour-e jadid.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Category:** enhancement

## Agent Brief

**Summary:** Yek mobile layout zir-e `md` (768px) ke rail rā be bottom nav, sidebar rā be off-canvas overlay, va
drawer rā be full-screen sheet tabdil mikonad; desktop dast-nakhorde mimānad.

**Current behavior:**
- Shell-e app se sotoon-e desktop-i darad: rail-e `w-[52px]`, sidebar-e `w-72`, va stage-e flex. Drawer yek
  strip-e `h-[42vh]` dakhel-e stage-e.
- Hich Tailwind breakpoint (`sm:`/`md:`/`lg:`) tooy shell nist. Dar width-haye kuchak-tar, majmooe-e fixed
  width-ha az viewport bishtar mishavad va safhe horizontal scroll mikhonad.
- Sidebar hich hālat-e bastan nadarad va hich kontroli baraye baz-kardan-e aan ru-ye mobile vojood nadarad.
- Had-e aghal-e poshtibani: **360px**; portrait va landscape.

**Desired behavior:**
- Zir-e **768px** (`md`):
  - **Rail → bottom nav**: hamoon action-haye rail (project, terminal, files) dar yek nav-e chasbide be
    paeen-e safhe; bottom-safe-area ra ehtiram bezanad (`env(safe-area-inset-bottom)`).
  - **Project sidebar → off-canvas overlay**: be soorat-e pishfarz penhan; az yek kontrol dar header-e chat
    baz mishavad; yek scrim posht-ash; ba entekhab-e project, click-e scrim, ya `Escape` baste mishavad.
  - **Bottom drawer → full-screen sheet**: terminal ya files tamam-e stage rā mipushānad (chat posht-ash
    penhan), ba kontrol-e close-e khod-ash; tab state-e hamishe (terminal ⇄ files) hefz mishavad.
  - Composer va dokme-haye chat dar paeen-e safhe kamel dide mishavand va ba safe area/focus-e input
    barkhord nadarand.
  - Safhe hich horizontal scroll-i nadarad — na chat, na History, na file drawer, na terminal.
- **≥ 768px**: layout daghighan mesl-e emrooz; hich test ya class-e desktop taghir nemikonad.

**Key interfaces:**
- Shell-e layout bayad yek breakpoint-e vahed (`md`, 768px) dashte bashad, na chandin rule-e parakande.
- `Drawer` bayad hamin `DrawerTab` state rā ba yek presentation-e mobile (full-screen) neshoon bedahad; tab-e
  khod-ash rā dobare nesazad.
- Header-e chat (ya yek top bar-e mobile) yek kontrol-e sidebar-toggle megirād; dar desktop penhan ast.
- Bottom nav va composer bayad safe-area inset rā be-kar begirand.

**Acceptance criteria:**
- [ ] Dar 360×640 hich horizontal scroll-i nist (chat, session history, file drawer, terminal).
- [ ] Zir-e 768px: rail be bottom nav tabdil mishavad va hamoon se action rā dārad; sidebar penhan ast ta
      baz beshavad; ba scrim/Escape/entekhab-e project baste mishavad.
- [ ] Zir-e 768px: baz-kardan-e terminal ya files chat rā mipushānad va yek close control-e vāzeh dārad.
- [ ] Composer va send button dar 360px kamel ghabele-dastresi hastand.
- [ ] Yek Playwright e2e ba viewport-e 360×640 in reflow rā pooshish midahad.
- [ ] Dar ≥768px layout va test-haye mojood bedoone taghir pass mishavand.
- [ ] `npm run typecheck` and `npm test` pass.

**Out of scope:**
- Touch gesture-ha (swipe, long-press, pinch) va touch-specific context menu-ha.
- Mobile keyboard/terminal input-e vizhe (xterm faghat bayad dar width-e mobile kār kone).
- Yek tarahi-e se-pane-ye jodagane baraye tablet.
- Taghir-e RTL behaviour (nabayad beshkast, vali kār-e jadid nist).

## Decisions from triage (2026-10-17)

- Awlawiat: mobile va browser-haye kam-width, had-e aghal **360px**.
- Sidebar: **off-canvas overlay**.
- Icon rail: **bottom nav**.
- Touch/gesture-ha **dar scope nistan**; faghat layout reflow.
- Drawer dar mobile: **full-screen sheet** (default-e triage; agar nazar-e digari hasti, in ticket rā
  update kon).
