# 79: Delete a session from disk

transcript-e SDK rā az disk hazf mikonad — bedoone store ya state-e jadid dar clodeck.

**Category:** enhancement

## Agent Brief

**Summary:** `DELETE /api/projects/:id/sessions/:sid` fayl-e JSONL-e un session rā az disk hazf konad; History
yek delete action ba confirm modal begirad; agar session-e bāz (jāri) hazf shod, chat be **New chat** bargardad.

**Current behavior:**
- History faghat do GET dārad (list + messages). Hich delete route/UI nist.
- Session-hā hich store-i dar clodeck nadārand; manba'-e vāghe'i `~/.claude/projects/<cwd>/<id>.jsonl`-e SDK
  ast (standing decision: clodeck hich chiz persist nemikonad).
- `SessionBrowser` har row rā ba `Resume` neshoon midahad; dokme-ye hazf nadārad.

**Desired behavior:**
- **Server**:
  - Route-e jadid `DELETE /api/projects/:id/sessions/:sid` → **204** ru-ye movafaghiat.
  - `sid` faghat vaghti ghabool ast ke `sid` dar `listSessions(project.path)`-e hamoon project bāshad; na
    strcat-e khām. `sid` nāshenās ya traversal-shape (mesl-e `../x`) → **404** va hich file-i hazf nemishavad.
  - Provider yek capability-e `deleteSession(sessionId, dir)` migirad; implementāsiun-e Anthropic fayl-e
    `<dir>/<sid>.jsonl` rā hazf mikonad (va agar SDK artifact-e jānai dige-i baraye hamoon session negah
    midārad, ānhā ham). Hich file-e dige-i laghv nemishavad.
  - Agar turn-i ke hamoon session rā dārad dar hāl-e ejrā-st → **409** ba code-e `turn_in_progress` va hich
    hazf-i; file dast-nakhorde mimānad. (Agar run dar hāl-e ejrā-st vali hanooz session-id nānde, hazf-e yek
    session-e kohne āzād ast.)
- **Client (History)**:
  - Har row yek delete action-e vāzeh dārad (dakhel-e `⋯` menu ya kenār-e `Resume` — shekl-e daghigh
    entekhāb-e agent ast, vali accessible label lāzem ast).
  - Ghabl az hazf yek **confirm modal** ke be-gooyad in transcript barā-ye hamishe hazf mishavad va dige
    resume-napazir ast. Cancel → hich chiz.
  - Sad az movafaghiat: row az list hazf mishavad va toast.
  - Agar session-e hazf-shode **transcript-e bāz** bāshad, panel be live bargardad (close).
  - Agar session-e hazf-shode **session-e jāri-ye live** bāshad, `New chat` ejrā shavad: live transcript,
    `sessionId`, resume target, va banner pāk beshavand; `clear_resume` be server ferestāde shavad.
  - Agar session-e hazf-shode **resume target-e armed** bāshad (banner), banner va target pāk beshavand.
  - Zaman-i ke hamoon session dar hāl-e ejrā-st, delete action disabled ast va tooltip-e mesl-e
    `a turn is running — interrupt it, or wait for it to finish` neshān dāde mishavad.
- Hazf **hard** ast: trash/undo nadārad. Login/auth session-hā hich taghiri nemikonand.

**Key interfaces:**
- `SdkProvider.deleteSession(sessionId: string, dir: string): Promise<void>` — yek capability-e jadid.
- REST: `DELETE /api/projects/:id/sessions/:sid` → `204` / `404` / `409`.
- `useSessions` yek `delete(sessionId)` action migirad ke state-e list va transcript rā ham-rāh konad.
- Reset-e session-e jāri az hamoon `newChat`-e mojood estefāde konad; yek reset-e dovom nasāzad.

**Out of scope:**

## Decisions from triage (2026-10-17)

- "Session" = **SDK conversation-e History**, na login session.
- Hazf: **file az disk** (JSONL delete), na hide-list; state-e jadid be clodeck tahmil nemishavad.
- Session-e jāri hazf beshavad → **New chat**.
- **Confirm modal** lāzem ast; hard delete (bedoone trash/undo).
- Vaghti turn dar hāl-e ejrā-st, hazf **masdood** ast.
