# 78: Download a folder as a zip

> *This was generated by AI during triage.*

**What to build:** Download-e clodeck faghat file ra pas midahad. `GET /projects/:id/files/download` ba
`resolveAs(..., 'file')` directory rā 400 mikhonad, va row menu-e tree aslan Download nadarad — dar hāli ke
toolbar-e panel baraye **har** entekhab (az jomle folder) yek Download link neshoon midahad. In ticket
folder download rā be soorat-e `.zip`-e stream shode misazad va har do voroodi rā ham-rāh mikonad.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Category:** enhancement

## Agent Brief

**Summary:** Yek directory (be joz root) be soorat-e `<name>.zip` download beshavad, az toolbar **va** row
menu-e tree; archive stream shavad, empty folder-hā hefz beshan, va symlink-haye kharej az project root skip
beshan.

**Current behavior:**
- Route-e download faghat file rā ghabool mikone; directory → 400.
- Toolbar-e panel baraye har entekhab Download neshoon midahad, pas entekhab-e yek folder yek link-e
  shekast-khorande ast.
- Row menu (`⋯`) faghat `Rename` va `Delete` dārad.

**Desired behavior:**
- Download-e yek **directory** yek attachment-e `.zip` bar migardānad:
  - `Content-Type: application/zip`; `Content-Disposition: attachment` ba `<name>.zip` (non-ASCII names →
    RFC 5987 / `filename*`).
  - Archive yek top-level directory ham-nām-e folder dārad (`src/` → `src.zip` ke baz shodan-ash `src/`
    misāzad), tā jozveh-hā ba mazmoone folder yek-ja nashavand.
  - **Empty directories** dar archive hefz mishan.
  - **Symlinks**: link-i ke `realpath`-ash az project root kharej ast **skip** mishavad (na follow, na
    include); link-i ke dakhel-e root mimānad be soorat-e target-ash (file/dir-e vāghe'i) archive mishavad.
  - **Bedoone size cap** va bedoone sakht-e tamām-e archive dar memory ya temp file: az disk be response
    stream mishavad.
  - Header-hā-ye entry: masir-hā hamishe nisbi, bedoone `..`, bedoone absolute; UTF-8 flag baraye
    name-haye Farsi.
- Root-e project **hargez** download nemishavad (hamān ghanoon-e "root never touched").
- Har do voroodi:
  - **Toolbar-e panel**: yek download action baraye entekhab-e file ya folder.
  - **Row menu-e tree va flat list**: `Download` baraye har do (file → file-e vāghe'i, folder → zip).
  - Download hamchonān yek anchor-e vāghe'i ast (`href` + `download`), na fetch-saz; toast-e
    `downloaded <name>` mesl-e emrooz.
- Khaṭā-hā: masire nāshenās → 404; root → 400; masire nimāyesh dādane-dige (na file na directory) → 400
  mesl-e emrooz.

**Key interfaces:**
- Download route bayad directory rā ham ghabool konad; file behaviour dast-nakhorde bemānad.
- Yek library-e zip-e **streaming** va maintain-shode (masalan `yazl`) ezāfe shavad; archive buffer nashavad va
  symlink/unicode/empty-dir ra khod-ash dašt-e konad ya explicit handle beshavad.
- File panel: yek action-e download-e moshtarak bayn toolbar va row menu; row menu-e folder va file yek raftār
  dārand.

**Acceptance criteria:**
- [ ] Download-e folder az toolbar va az row menu, har do `<folder>.zip` save mikonand.
- [ ] Zip round-trip: structure-e nisbi yeksān, byte-hā-ye file-hā yeksān, empty directory-hā mojood.
- [ ] Symlink-e kharej az root dar zip nist; symlink-e dakhel-e root ba byte-hā-ye target-ash mojood ast.
- [ ] Name-hā-ye Farsi (file va folder) bedoone tabdil dar zip mimānanad.
- [ ] Hich entry-i absolute path ya `..` nadārad; download-e root 400 midahad.
- [ ] Test-hā: server (file, folder, root, escaping symlink, empty dir, non-ASCII) va web (har do voroodi).
- [ ] `npm run typecheck` and `npm test` pass.

**Out of scope:**
- UI-e download progress ya cancel.
- Size limit, rate limiting, ya cleanup-e server-side.
- Format-hā-ye dige (tar, tar.gz).
- Download-e chandin entekhab-e ham-zamān.

## Decisions from triage (2026-10-17)

- Format: **`.zip`**.
- Jā-ye dokme: **ham context menu-e tree, ham toolbar-e panel**.
- Empty folder-hā: **hefz**.
- Symlink-hā-ye kharej az containment: **skip**.
- Size cap: **nadārad**; stream (default-e triage).
